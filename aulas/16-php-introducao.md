# Aula 16 — PHP: primeiros passos

**Objetivo:** iniciar a parte lógica após concluir o front-end.

```php
<?php
$mensagem = "Estou aprendendo PHP";
echo $mensagem;
?>
```

PHP roda no servidor. `<?php` inicia o código; `$` identifica variável; `echo` imprime conteúdo; ponto e vírgula encerra a instrução.

**Executar:** coloque o projeto em `htdocs`, inicie Apache no XAMPP e acesse `http://localhost/estudos-html-css-bootstrap-php/teste.php`.

**Exercícios:** crie uma variável com seu nome e outra numérica. Mostre ambas com echo. Explique por que não basta dar duplo clique no PHP.
