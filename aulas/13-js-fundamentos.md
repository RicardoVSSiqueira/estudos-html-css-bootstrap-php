# Aula 13 — JavaScript: variáveis e primeiros comandos

**Objetivo:** criar variáveis e visualizar valores.

```javascript
const nome = "Ricardo";
let saldo = 1000;
console.log(nome);
console.log(saldo);
```

`const` declara uma variável que não será reatribuída; `let` permite reatribuição; `console.log` mostra informações no Console.

**Pratique:** abra `assets/js/script.js`, crie duas variáveis e veja os valores no Console do navegador (F12).

**Exercícios:** qual a diferença entre let e const? Crie uma variável de texto e uma numérica.
