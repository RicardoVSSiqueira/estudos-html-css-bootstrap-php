# Aula 02 — HTML: textos, links e imagens

**Objetivo:** apresentar textos, navegar entre páginas e exibir imagens.

```html
<h1>Meu painel</h1>
<h2>Resumo do mês</h2>
<p>Acompanhe suas despesas.</p>
<a href="gastos.html">Ver gastos</a>
<img src="assets/img/logo.png" alt="Logo Minhas Finanças">
```

`h1` a `h6` organizam títulos; `p` cria parágrafo; `a` cria link; `href` define o destino; `img` mostra imagem; `src` define o caminho; `alt` descreve a imagem.

**Pratique:** crie um subtítulo, um link para uma página futura e adicione uma imagem na pasta `assets/img`.

**Exercícios:** diferença entre `h1` e `h2`? Para que serve `href`? Por que usar `alt`?
