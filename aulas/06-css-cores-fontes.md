# Aula 06 — CSS: cores, fontes e textos

**Objetivo:** controlar a aparência dos textos.

```css
body {
    font-family: Arial, Helvetica, sans-serif;
    font-size: 14px;
    color: #f4f6fb;
    background-color: #080d18;
}
h1 {
    font-size: 28px;
    font-weight: bold;
    text-align: left;
    letter-spacing: 1px;
}
```

`font-family` escolhe fonte; `font-size` tamanho; `font-weight` espessura; `text-align` alinhamento; `letter-spacing` espaço entre letras; `color` cor do texto.

**Pratique:** altere a cor do título e aumente seu tamanho. Mantenha contraste para facilitar a leitura.

**Exercícios:** o que faz `font-weight`? E `text-align`? O que representa uma cor hexadecimal como `#10b981`?
