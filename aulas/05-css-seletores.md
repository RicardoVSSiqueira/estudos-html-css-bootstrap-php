# Aula 05 — CSS: conexão e seletores

**Objetivo:** conectar CSS ao HTML e selecionar elementos.

No `head`:
```html
<link rel="stylesheet" href="assets/css/style.css">
```

No CSS:
```css
body { background-color: #080d18; color: white; }
h1 { font-size: 28px; }
.card-resumo { background-color: #101827; }
#titulo { color: #10b981; }
```

Seletor de tag: `p`; classe: `.card-resumo`; id: `#titulo`.

**Pratique:** crie uma classe `.destaque`, aplique em um parágrafo e altere sua cor.

**Exercícios:** explique a diferença entre tag, classe e id. Crie um exemplo de cada.
