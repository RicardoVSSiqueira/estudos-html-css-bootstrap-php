## Como avançar

- Leia a explicação.
- Faça o passo a passo no seu computador.
- Digite o código e tente entender cada linha.
- Faça o exercício sem copiar a resposta.
- Só avance quando conseguir explicar o que fez.

Os valores que aparecem no painel inicial são exemplos fictícios. O banco de dados e as operações reais serão implementados nas aulas de PHP e MySQL.
