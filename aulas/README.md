## Como estudar
- Leia uma aula por vez.
- Digite os exemplos no seu computador.
- Teste no navegador.
- Faça os exercícios sem copiar.
- Só avance quando conseguir explicar o que fez.

> Esta trilha detalhada é o caminho principal. Os arquivos introdutórios anteriores permanecem como material complementar.
