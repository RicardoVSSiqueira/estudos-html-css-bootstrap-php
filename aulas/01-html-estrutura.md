# Aula 01 — HTML: estrutura do documento

**Objetivo:** criar a base de uma página.

```html
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minhas Finanças</title>
</head>
<body>
    <h1>Minhas Finanças</h1>
    <p>Meu primeiro projeto web.</p>
</body>
</html>
```

**Entenda:** `DOCTYPE` informa HTML5; `html` envolve o documento; `head` guarda configurações; `title` define o nome da aba; `body` contém o que aparece na página; `h1` é o título principal; `p` é um parágrafo.

**Pratique:** crie o arquivo `teste.html`, digite o exemplo, altere o título e adicione dois parágrafos.

**Exercícios:** qual a função de `head`? E de `body`? Para que serve `meta charset`?
